# StudyNotes-BIT 📚

A personal collection of semester notes, assignments, and study materials for my BIT (Bachelor of Information Technology) coursework — Semester 2.

## 📁 Repository Structure

```
StudyNotes-BIT/
├── GraphicsNOTES/          # Computer Graphics, 3D concepts, intro Python
├── Methodology & MPL/      # Research Methodology & MPL notes, assignments
├── Others/                 # Networking, AWS, Microsoft Office/Publisher, misc
├── SYSAdmin/                # Linux, NGINX, Systems Administration notes
├── Web2/                   # PHP, PHP OOP, CRUD, AWS deployment guides
├── PythonLearning/         # Python learning exercises
└── Semi2.pdf               # Semester 2 summary/reference
```

### GraphicsNOTES
Computer Graphics theory, 3D concepts, and supplementary Python programming notes.

### Methodology & MPL
Research Methodology and MPL (Management Principles of Leadership) course materials — includes lecture notes, chapter guides, past assignments, and study questions.

### Others
A mix of general IT topics: computer networking basics, IP addressing & subnetting, AWS hosting guides, and Microsoft Office/Publisher training material.

### SYSAdmin
Computer Systems Administration notes covering Linux fundamentals and NGINX configuration, plus test/quiz materials.

### Web2
Web Development II notes — PHP fundamentals, PHP OOP concepts, CRUD operations, and AWS deployment guides.

### PythonLearning
A separate learning log/repo for practicing Python.

## 🎯 Purpose

This repo serves as a personal backup and organized reference for revision, assignments, and exam preparation throughout BIT Semester 2.

## 📌 Notes

- File formats include `.pdf`, `.docx`, `.odt`, and images (`.jpg`/`.jpeg`) used for scanned notes or diagrams.
- Content is organized by course/topic folder for easy navigation.
